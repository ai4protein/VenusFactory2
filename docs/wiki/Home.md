## How docs are organized

1. **README** — clone, one-click install, open the UI  
2. **This wiki** — install details, catalogs, WebUI map, CLI/API  
3. **[Manuals](../manual/)** — click-by-click guides for each feature (also linked from the in-app Manual tab)

Do **not** mix layers: install questions → Installation; “which button?” → Manual; “what models exist?” → Models/Checkpoints.
