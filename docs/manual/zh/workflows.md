# 构建可复用工作流

## 什么情况使用

步骤和数据流已经明确、还要重复运行时，使用 Workflows。探索性问题用 Agent；方法本身还需研究和开发时用 Scientist。

## 添加并连接步骤

1. 打开 Workflows，给流程命名，从分类目录选择工具或模型。
2. 添加第一步所需的输入文件或数据。
3. 拖动卡片布局，将上游输出连接到兼容的下游输入。连线决定数据来源，卡片的位置本身不建立依赖。
4. 打开每张卡片设置必要输入和模型参数，不需要的卡片使用删除按钮移除。
5. 运行前保存工作流，之后可重新打开编辑或复用。

例如：获取序列、计算性质，再把合适的序列文件传给预测器。PDB 输出不能不经转换就接到任意 CSV 输入。

## 训练与注册工具

目录可包含已注册工具和自定义模型训练组件。提供训练数据或配置，再把模型输出连接到兼容的预测步骤。训练进入共享队列，线上 ESM2-8M 和工具权限限制仍然适用。

只有开启的组件才能执行，保存的流程不会让后来已禁用或移除的模型重新获得权限。

## 执行与检查

核对必要输入，保存后运行。跟踪作业与各步骤结果，打开产物；某一步失败时先查看该步骤信息，再修正重试。工作流定义和作业结果分别保存，保存流程不等于执行成功。

## 输入数据与连接

输入数据卡片选择一个已上传的数据集：CSV、TSV、JSON 每行一条样本；FASTA 转成 `id` 和 `sequence` 两列；PDB/PDBQT 是结构文件，SDF/MOL 是小分子文件。在使用数据的步骤中选择序列、特征与目标列。对接配体等额外文件在模型设置里选择。

连接传递上游的实际输出，执行顺序由依赖决定，与卡片摆放位置无关。预测步骤分别接入数据和训练模型。每个输入只有一个来源，重新选择会替换该输入的原连接。循环、不兼容的数据类型和错误端口不能运行。已有列在提交前检查；计算生成的列会在下一步执行前再次检查。

执行中，完成的连接变绿，正在传递的连接显示动画。点击执行过程中的步骤，可查看输入输出预览、记录数、耗时及处理日志。注册工具显示逐记录进度；没有内部进度回调的模型显示运行状态，完成后显示结果。步骤出错后不继续执行后续步骤，刷新后仍可查看作业记录。


## 我的作业与每日额度

点击工作流步骤提示旁的 **我的作业**，按名称或作业号搜索、按类型和状态筛选，再展开作业查看结果。作业面板不会挤压工作流画布，只展示当前浏览器工作区的作业。

线上每位访客每天可启动 **5 次工作流**，并在模型广场、Workflow 和 Chat 三种模式之间共享 **20 次模型推理**。工作流中的每个模型预测步骤计为一次推理，整个工作流入队前统一核算。数据库检索、基础理化性质计算不占模型推理额度。重试会启动一次新执行；刷新页面和查看结果不扣额度。

页面显示剩余额度，超额提交会提示重置时间。同一 IP 下的不同访客各自计数，IP 仅用于短时高频限制。本地部署不设每日额度。
