# Library 与对话文件

## 上传材料

使用输入框的上传图标、拖拽文件到上传区域，或从剪贴板粘贴文件。Scientist 研究和 Researcher 报告都可添加多个材料文件；普通文本粘贴仍是消息内容。

在线上传**每个文件不超过 10 MB**，本地不设平台上传大小上限。接受格式由使用入口决定：预测和训练使用表格、序列，结构任务使用结构文件，研究材料还可包括论文和笔记。

## 打开文件面板

点击 Chat 右上角文件图标，按名称搜索、按类型或日期筛选。可预览支持的文件、单独下载结果，或使用提供的打包下载操作。结构文件可打开结构查看器，通过序列选择和显示控制检查残基；不支持预览的格式可在权限允许时下载。

## 浏览文件库

文件库仅本地模式可用。Online 模式下进入文件库会显示空页面和“Online 模式不可用”。线上可通过每个对话右上角的文件面板查看、下载该对话的材料与结果。

## 复用数据

输入入口提供 Library 选择器时，可选择已有且有权访问的文件，也可以下载后重新上传。向 Agent 说明文件名和用途，不要引用其他会话的宿主目录路径；沙箱程序只看到分配给当前会话的目录。
