# RSI 广场

进入 **模型广场 → RSI 广场**，浏览 Scientist 开发的研究项目。

## 查看案例

按项目名称或科学课题搜索。打开案例后可阅读 README、浏览项目目录，预览代码、报告及支持的文本文件。案例展示研究范围与已有评估证据。

点击 **下载 ZIP** 保存项目压缩包。复现前阅读包内 README 和依赖说明。研究可能尚未完成或未通过科学验收，使用结论前应检查报告。

## 可见范围

私有研究项目仅本人可见；公开案例由平台负责人筛选发布，并展示作者与共享信息。分享案例不会公开其他对话或未发布研究文件。

RSI 广场提供仓库浏览和下载，不启动预测、不发布 MCP 工具，也不把模型注册到 Agent 或 Researcher。运行已有预测模型请使用普通模型广场，开展新课题请进入 [Scientist](manual:scientist)。

本地模式也可浏览部署者已有 RSI 研究库中的记录案例，下载保存的模型代码、参数和评估。记录案例不代表整个课题已经完整复现；没有独立发布授权的本地研究库不会在线上公开。
