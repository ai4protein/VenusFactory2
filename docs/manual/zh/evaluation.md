# 评估模型

## 使用独立数据

提供没有用于拟合或选择模型的带标签序列。标签定义、测量单位和预处理与训练保持一致。若要验证跨蛋白泛化，应保留蛋白家族或序列组隔离的数据划分。

## 运行评估

1. 从模型广场打开自定义模型 Evaluation。
2. 选择 checkpoint 和匹配配置，添加评估数据并指定必要列。
3. 选择适合任务的指标，提交后进入队列。
4. 同时检查指标和逐样本预测，核对失败行、样本数和类别分布。

分类任务应考虑类别不平衡，按适用条件查看 MCC、精确率、召回率、F1、AUROC 等。回归任务同时看误差、排序或相关性指标，以及测量值范围。不同划分或标签尺度的指标不能直接比较。

## 比较方法

基线和候选模型使用相同划分、目标定义与评估流程。简单方法也可以是有效成果。样本量允许时报告不确定性或变异，不要无说明地丢弃失败样本。

## 共享模型

完成评估不会自动注册公共模型。Scientist 发布还需接口测试、复现证据、适用范围和独立审核。将权重、配置、划分说明与评估结果一起保留，详见 [Scientist](manual:scientist)。
