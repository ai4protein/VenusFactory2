# 使用模型预测

## 选择入口

平台预测器从[模型广场](./zh/models.md)卡片进入。自己的训练模型从自定义模型 Prediction 进入，选择匹配的 checkpoint 和配置。Scientist 产物应先查看注册时的输入接口和生物适用范围。

## 准备输入

- **单条序列**：在序列框粘贴氨基酸序列，遵循表单对 FASTA 或纯序列的要求。
- **批量预测**：上传表格或序列文件，按提示选择序列列。为每行保留样本标识，便于回连结果。
- **结构与设计**：提供所需的 PDB/mmCIF 或其他支持格式，检查链、残基、采样设置。
- **小分子**：按分子工具要求提供 SMILES 或结构文件；蛋白序列不是 ADMET 的输入。

自定义 checkpoint 要与训练时的骨干、训练方法、池化方式和标签映射一致，名称相近的骨干不一定兼容。

## 提交并取回结果

1. 选择已开启模型，检查相关参数。
2. 提交一次，保存作业号，跟踪排队、运行和完成状态。
3. 打开结果表并下载文件。批量任务应核对样本编号和有效预测数量是否匹配。
4. 选取实验候选前记录模型版本、单位、分数方向和局限。

作业属于提交时的用户或浏览器身份。找不到结果时，回到原浏览器或原对话查找，不要猜测其他用户的作业号。

## 在 Chat 使用

向 Agent 上传输入并说明预测性质，它可以搜索当前工具目录，补问缺失信息，再调用已开启的预测器。需要把预测与文献整合为长报告时使用 Researcher。

禁用模型不能通过 Chat 调用。预测成功是计算结果，不等于实验验证；衡量预测能力需要独立标签集与[模型评估](./zh/evaluation.md)。
