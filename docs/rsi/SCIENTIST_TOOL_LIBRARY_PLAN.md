# Scientist RSI: 10,000 specialized protein models

The primary research contribution is a persistent Scientist that develops, verifies,
registers and reuses executable protein-research tools, then improves the procedure
that develops later tools. Interactive Agent is the consumer of the growing library.
Published-study reproductions provide tasks and reference outputs, not mandatory
VHH/PET headline cases. The manuscript title is unchanged.

## Evidence boundary and execution policy

The target is 10,000+ trained, verified and callable protein/property/scenario-specific models. It is not an observed result. The same algorithm may support distinct validated scopes. The existing shared
library index contains 13 source-generated model entries, 11 source programs and

independent study replay; the preceding full-library replay covered ten entries
across nine scopes. These counts do not represent new algorithms. Historical
source transfer and goal comparisons retain their negative outcomes. Current
autonomous publication is strongest for generated regression and classification.
General analytical-tool publication is an implementation milestone below.

New model requests use only approved free routes: DMX glm-4-flash and
unisound-u2-flash, plus exact zero-price OpenRouter free variants under the new
request and response cost controls. Access recovered on 2026-10-24. Bounded real acquisition
pilots now run from frozen source copies. Preserve observed GLM code-generation and
Unisound profile failures; scale after real models pass registration and fresh reuse.

## Count what was actually acquired

The primary target counts trained, independently validated and callable models for
specific protein/property/scenario scopes. Different proteins with the same property,
different properties of one protein, and distinct measured scenarios may use the same
algorithm and count separately. Algorithmic diversity is a separate result. Seeds,
renamed wrappers, repeated fitting, resplits and re-registration of the same scope do
not increase the primary model count; revisions form a versioned lineage.

Report candidate tasks, fitted models, verified released models, protein scopes,
properties, scenarios, algorithm families, baseline wins and successful later uses
separately. Model count does not equal independent biological replication. Analytical
tools and imported author software are separate supporting inventories. Source-driven
admission and the source expansion plan are specified in
`docs/rsi/RESEARCH_PROJECT_MODELS_10000.md`.

## Experiments that support the central claim

E1: Acquisition and validity. After a successful free-model preflight, validate a
small project-derived pilot, then expand through 32, 128, 512, 1,000, 3,000 and 10,000+
verified model scopes. These are planning checkpoints, not completed counts. Pause
expansion for unresolved correctness or duplication failures. Independently audit
all primary counted entries and report failures and observed development cost.

E2: Cumulative utility. Freeze library snapshots chronologically. On tasks selected
before acquisition, compare fixed starting tools, acquisition without cross-goal
reuse, and acquisition with reuse under the same LLM, harness and total resource
budget. Measure complete-task success, endpoint-specific scientific quality, time,
model calls and reuse frequency. Do not select a snapshot using test performance.

E3: Recursive improvement. Compare fixed strategy versus revised strategy with
the same starting library, information and total development-plus-evaluation budget.
Add an equal-budget extra-search control. Promotion uses a development task block;
final descendants face separate protein/assay groups. Trace the chain from strategy
change to new tools to later-task benefit. Library growth alone is not this test.

E4: Coordination and portability. Use a persistent single-agent control to separate
long execution from expert roles. Test harness and LLM portability only after the
primary fixed-backend comparison works. Preserve failed or unsupported combinations.

A provisional evaluation pool can cover about 20 held-out goals per capability
class (about 120 total), with multiple independently initialized campaigns. Final
sample sizes and replication are set from pilot variance and compute limits before
opening final outcomes. Cluster uncertainty by campaign and protein/assay group;
tool count and overlapping task splits are not independent biological replicates.
