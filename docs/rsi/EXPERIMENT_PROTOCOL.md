# 论文级蛋白案例的 RSI 实验协议

2026-10-11 本版替代旧的 120 道任务计划。论文题目为 **Self-evolving AI agents for protein discovery and directed evolution**。H1/H2/H3 是已确认的研究问题，尚无正式效果结论。实现仅在 hl_gpu 的 VenusFactory2 / `codex/rsi-pilot`；当前新协议固定 DMXAPI `glm-5.1`；历史 `glm-4-flash` 先导单独保留，不与新协议合并。

完整选题、原始论文、工作链、限制及改造依赖见 案例方案 (local research archive)，机器清单见 `configs/rsi/paper_cases.json`。VenusAgentEval 停止作为开发/选择/最终测评来源；历史小案例只作功能档案。合成 smoke 保留作工程回归，不进入科研结果。

## 1 实验单位与轨道

六项主案例为 ALDE、McbA、NucB、GB1 外推、TurboPETase 和 RFantibody。REAP、Germinal 为扩展迁移候选；FAST/HotPETase 为 PET 跨论文参考。最终纳入和排除依据数据、版本、许可及完整工作链可获得性，在正式结果揭盲前锁定并公布，不按 agent 成绩筛选。

开放资料作者复现轨道允许完整论文和代码，评价计算链、阶段产物与结果一致性。受限资料迁移轨道先冻结材料与标签，再评价新会话/目标/家族的收益；不宣称公开论文从未进入基础模型训练。前瞻实验轨道独立设计并单独报告。

分组同时考虑论文来源、蛋白同源族、底物条件和实验轮次。共享 GB1 数据必须在一个隔离块；McbA 的九个底物不是九个独立家族；NucB 的多代重复序列需要去重/显式分组。不得按样本行数伪造独立 agent 任务量。

## 1.1 双模式与模型开发的新增比较

论文贡献定位见 [双模式与自主模型开发修订](../paper/plan/DUAL_MODE_MODEL_EVOLUTION_20261011.md)。Science 为专家团围绕明确目标的持续执行；Agent 为自由问答和按需工具调用，以用户回合为完成单位。持续单智能体只作为显式研究对照，不改变 Agent 产品语义。已有代码提供两条独立路径；自动模式选择、无损交接和跨模式能力复用尚待验证。

先在预先选定的代表 case 上，以同一 GLM、同一必要工具、输入与预算比较通用运行时加领域工具、冻结 Scientist、冻结 Agent。逐项消融领域产物检查、能力选择及恢复策略，但所有组保留相同外部评价。受控反馈协议使用预定义的相同信息；真实人机协作另报人工干预内容、次数与时间。不能把不同人工帮助或不同模型带来的效果归给模式设计。

下述 B1–B5 是能力积累/改进策略轴，不与模式轴混为一谈。能力积累/改进策略对照与产品模式比较分别冻结；需要多 episode 的单智能体必须显式标成实验控制组。新的完整目标三组对照见 模式实验协议 (local research archive)，不得把模式或持续执行差异归给演化。实验不会默认执行全部笛卡尔组合，正式比较范围须在看最终结果之前冻结。

新增模型开发记录：缺口判定、选择复用/适配/生成代码/停止的理由、数据与划分、特征/模型方案、代码差异、训练、独立验证、checkpoint 与预测入口、适用条件及未来调用。区分现成模型调用、既定训练配置、程序生成建模和算法创新。先覆盖 McbA、NucB，再扩展数据充分的 VHH/PET 等问题；每个新模型均与作者或标准建模方法进行同数据/预算比较。

## 2 对照组

| 组 | 跨案例允许变化 | 比较目的 |
| --- | --- | --- |
| A 作者参考算法/流程 | 按原论文设定 | 定义复现参考和领域强基线 |
| B1 修复后冻结 VF | 无持久变化；单次任务可训练和调试 | 当前完整工具系统基线 |
| B2 经验记忆 | 等容量、可溯源记忆 | 排除仅因多看经验产生的收益 |
| B3 固定 U | 执行提示、技能、工作流、模型资源可变；U0 固定 | 持续学习直接对照 |
| B4 可演化 U | B3 的执行对象与下一轮实际调用的 U | 检验递归贡献 |
| B5 GEPA | 官方过程优化执行提示 | 提示优化强基线 |

各 agent 组使用相同模型别名、必要工具、基础可靠性修复、初始资源和总预算。相同工具权限包括任务内训练与调试；不通过剥夺基线必需工具制造优势。GEPA 未实际接入前不能把手写提示反思循环称为 GEPA。可另适配 MetaHarness，但不能将 B3 更名重复计数。

## 3 case 准入及执行合同

先完成来源锁、完整输入、作者版本与依赖、作者输出、明确指标和容差、case 内数据划分、预算和停止规则，才进入 agent 比较。数据下载/代码存在仅完成来源层。环境和模型权重应有摘要；软件升级或替代算法分别报告。

case runner 应执行声明的阶段 DAG，保存真实工具调用和结果、文件哈希、脚本、checkpoint、候选、验证结果、总成本、人工干预与失败。只输出计划或漂亮报告不能通过。已有分阶段 runner、注册复现插件、独立模型验收和目标控制器；仅接通并通过独立核验的 case 可评分。下载资料或存在适配接口仍不能视为计算链完成。

科研容差由作者方法/数值复算与先导确定。不得在看最终组间差异后挑选指标、容差或成功阈值。所有未完成阶段列出原因、耗时和已有产物。

## 4 H1 能力积累、迁移和遗忘

开发案例按预定不同顺序运行多条独立谱系，每条从相同初始版本开始。每个能力对象保留失败证据、内容差异、验证、适用范围及后续调用。新会话携带经过批准的能力对象，不携带前例私有答案和测量标签。

最终迁移使用冻结能力与执行策略，不再根据最终反馈改进。比较领域完成率、科学终点、总成本和人工干预；另外运行原任务回归报告遗忘。共同能力包、删除新增能力、只保留记忆和适用域检查消融用于归因。

## 5 H2 改进器独立反事实

从同一初始/中期/最终 E、原始完整历史 H、可见资源及预算 B，分别加载 U0 与 Ut。每侧在同一开发/选择材料上产生和选择后代，再到独立后代审计 case 评分；测试结果不返还 U。比较的是实际被选择的后代，不是测试集上事后最佳后代。

主要量为 Delta_meta(B) = Q_audit(E_selected(Ut,E,H,B)) - Q_audit(E_selected(U0,E,H,B))。审计质量按预先指定的各 case 指标分别计算；不混合不兼容生物量纲。U 的提炼、meta-probe 和候选验证计入总预算。增加 U 回退、相同历史和等容量记忆对照，报告失败提案和成本。

每个先导比较至少 3 次独立搜索仅用于估方差和成本；正式谱系数需要在盲测前根据最小有意义效应确定。API 不支持种子时使用独立会话并记录，不假称可控制全部随机性。H2 不支持时，只能报告能力扩展/适应，不能用“复现了很多论文”替代递归证据。

## 6 H3 领域价值与历史反馈

同信息比较让各组接收相同批次测量。闭环回溯比较则固定已测候选池和初始观测，以受限 oracle 按查询扣费，允许后续标签因选择不同而不同。未测序列返回 unavailable，不填零、不用代理预测假装测量，也不利用全表估算未观测候选的真实 regret。

历史轨迹只支持相应测量范围内的决策分析，已发表筛选库存在选择偏差。固定测量/算力预算下报告排序、top-k 已测命中、活性-多样性或条件一致的性质取舍。PET 保留温度/pH/底物/酶量/时间，抗体结构评分与亲和力分开。

前瞻湿实验需冻结候选选择与对照，保留表达失败和无改善结果，单独设置生物重复、批次与功效。计算复现不包含原作者的实验执行。

## 7 标签隔离与统计

完整来源缓存和评价标签只供控制器/复现审计，不挂载到 agent、MCP、训练进程或下载工具。当前共享 network 能访问论文答案，正式受限资料轨道必须使用资料快照、限制域名/资料访问并记录响应；仅从提示词删除答案不构成盲化。先验证文件/网络隔离，再运行正式比较。

主统计按独立 campaign/蛋白族与谱系分层，采用配对比较，报告逐案例结果、区间、失败和全部成本。随机种子、序列、反应条件和技术重复不是同一种独立单位。预先区分主要指标与探索性指标，保留负结果及版本变更原因。
